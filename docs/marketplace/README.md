# NNBot 插件市场

欢迎使用 NNBot 插件市场！本指南将帮助你发现、安装和管理 NNBot 插件。

## 快速开始

### 访问市场

1. **WebUI**：访问 `http://你的NNBot地址:8080`，点击侧边栏「插件市场」
2. **命令行**：在聊天中使用 `/plugin` 命令

### 浏览插件

**WebUI**：
- 访问市场首页
- 使用搜索栏查找插件
- 使用分类标签按类别浏览
- 查看热门和推荐插件

**命令行**：
```
/plugin search <关键词>
/plugin popular
/plugin recommended
```

### 安装插件

**WebUI**：
1. 找到想安装的插件
2. 点击插件卡片查看详情
3. 点击「安装」按钮
4. 等待安装完成

**命令行**：
```
/plugin install <插件ID>
```

示例：
```
/plugin install username/plugin-name
```

### 查看已安装插件

**WebUI**：
- 点击「已安装插件」按钮
- 查看所有已安装插件及其状态

**命令行**：
```
/plugin list
```

### 更新插件

**WebUI**：
1. 进入「已安装插件」页面
2. 点击有可用更新的插件旁的「更新」按钮
3. 或点击「全部更新」更新所有插件

**命令行**：
```
/plugin update <插件ID>
/plugin update --all
```

### 卸载插件

**WebUI**：
1. 进入「已安装插件」页面
2. 点击要卸载的插件旁的「卸载」按钮
3. 确认卸载

**命令行**：
```
/plugin uninstall <插件ID>
```

## 插件命令参考

| 命令 | 说明 |
|------|------|
| `/plugin search <关键词>` | 按关键词搜索插件 |
| `/plugin info <插件ID>` | 查看插件详情 |
| `/plugin install <插件ID>` | 安装插件 |
| `/plugin uninstall <插件ID>` | 卸载插件 |
| `/plugin update <插件ID>` | 更新单个插件 |
| `/plugin update --all` | 更新所有插件 |
| `/plugin list` | 列出已安装插件 |
| `/plugin popular` | 查看热门插件 |
| `/plugin recommended` | 查看推荐插件 |
| `/plugin help` | 显示命令帮助 |

## 插件 ID 格式

插件 ID 格式为：`用户名/插件名`

示例：
- `nnbot/ai-chat`
- `user/weather-plugin`
- `admin/moderation`

## 自动更新

市场插件每 24 小时自动检查更新。有可用更新时，会在聊天中通知你。

要禁用自动更新，可以卸载市场插件：
```
/admin unload marketplace
```

## 常见问题

### 找不到插件

如果显示「插件未找到」：
- 检查插件 ID 格式（`用户名/插件名`）
- 确保插件存在于市场中
- 尝试先搜索插件

### 安装失败

如果安装失败：
- 检查网络连接
- 验证插件文件是否有效
- 查看错误消息了解详情

### 没有可用更新

如果没有可用更新：
- 插件已是最新版本
- 市场可能还没有最新版本

### 插件不工作

如果插件安装后不工作：
1. 检查插件是否启用（`/plugin list`）
2. 重启 NNBot 重新加载插件
3. 查看插件文档了解配置要求

## 获取帮助

- **文档**：查看插件的 README 了解具体说明
- **问题**：在插件仓库中报告问题
- **支持**：在 NNBot 社区寻求帮助
